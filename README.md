# Galaxy Explorer Pro

An interactive 3D solar system explorer built with Three.js and Vite.

## Development

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start development server:
   ```bash
   npm run dev
   ```

3. Open http://localhost:3000 in your browser.

## Deployment to GitHub Pages

1. Make sure you have committed all your changes.

2. Build the project:
   ```bash
   npm run build
   ```

3. Deploy to GitHub Pages:
   ```bash
   npm run deploy
   ```

4. Your site will be live at: https://oalalif.github.io/galaxy-explorer-pro/

## Project Structure

- `/src` - Source files
- `/public` - Static assets
- `/dist` - Built files (automatically generated)
